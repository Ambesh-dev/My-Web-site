# GitHub Pages Upload

1. Extract this ZIP.
2. Upload all files directly into the root of your GitHub repository.
3. Before publishing, configure `supabase-config.js` with your Supabase URL and anon/public key.
4. Commit the files.
5. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → root.

Public website:
`https://YOUR-USERNAME.github.io/YOUR-REPO/`

Admin panel:
`https://YOUR-USERNAME.github.io/YOUR-REPO/admin.html`

The Admin Panel is online and uses Supabase, so changes made from a phone or PC update the same public website.
